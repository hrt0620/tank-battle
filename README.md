# 🛡️ 坦克大战 · Tank Battle

经典 90 年代街机风格的坦克大战，纯 **HTML5 Canvas** 实现，无需任何依赖，单文件即可运行。

## ✨ 功能特性

- 🎮 玩家坦克：方向键 / WASD 移动，空格 / J 开火
- 👾 敌人 AI：自动寻路、随机转向、主动射击
- 🧱 可破坏的砖墙、不可摧毁的钢墙
- 🌊 水面（不可通行）、🌳 树丛（可通行并遮挡视线）、🧊 冰面
- 🦅 保护基地（老鹰），基地被毁则游戏结束
- 📈 关卡递增，敌人数量与难度逐关提升
- 🔊 音效（Web Audio，无需外部文件）
- 💯 计分系统、生命系统、暂停功能

## 🎮 操作说明

| 按键 | 功能 |
| ---- | ---- |
| `W A S D` / `方向键` | 移动坦克 |
| `空格` / `J` | 开火 |
| `P` | 暂停 / 继续 |
| `Enter` | 开始 / 重新开始 |

## 📝 玩法目标

消灭每一关的所有敌人，并保护己方基地不被摧毁。你拥有 3 条生命，被击中会短暂无敌后重生。
